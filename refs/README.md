# Reference material (not committed)

`refs/papers/` and `refs/source/` are **git-ignored**. They hold the primary
sources this tool was reconstructed from: publisher PDFs (copyright) and clones
of upstream repositories. They are kept on disk for provenance and re-checking,
not redistributed here.

To re-fetch, see `docs/DESIGN.md`, which cites every source by DOI/URL and maps
each capability of this tool back to the specific paper, equation or source file
it came from.
